# Reinos de Hierro

RTS jugable en HTML inspirado en los clásicos de estrategia en tiempo real.

## Jugar

Abre `index.html` en un navegador moderno.

## Controles

- Arrastra con el ratón para seleccionar unidades.
- Clic derecho para mover, recolectar o atacar.
- WASD o flechas para mover la cámara.
- Rueda del ratón para hacer zoom.

## Sistemas incluidos

- Aldeanos y unidades militares.
- Madera, comida, piedra y oro.
- Construcción de casas, cuarteles, galerías, establos, torres y maravilla.
- Entrenamiento de unidades y límite de población.
- Tres edades tecnológicas.
- Combate cuerpo a cuerpo y a distancia.
- Oleadas enemigas progresivas.
- Victoria al destruir el castillo enemigo.
- Pausa, reinicio, derrota y registro de eventos.

Todo funciona sin dependencias externas y está contenido en `index.html`.
